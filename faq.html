FAQ

What is hue.tf?

hue.tf is a browser-based colour palette tool. Drop in an image, extract a palette, refine the colours, and export the result as a showcase image, code tokens, or an Adobe swatch file.

All image processing happens in the current browser tab. The original image is not uploaded to a server.

Which image formats can be used?

WebP, AVIF, PNG, JPEG, and SVG, depending on what the browser can decode. If a file fails to open, convert it to PNG or JPEG and try again.

How to use the .ASE file?

Download the .ASE file from the Adobe Swatch tab in the Export dialog. In Photoshop, Illustrator, or InDesign, open the Swatches panel menu and choose the option to open or import swatches. In Procreate, use the palette import option.

The file contains the palette colours only, not the original image.

How can a bug be reported or a feature requested?

Open an issue on the Codeberg repository. Include the browser and version, operating system, steps to reproduce, and whether canvas access is blocked. Screenshots are helpful.

How can I support the project?

Donations are optional and can be made through Ko-fi or Liberapay on the donation page. Sharing the tool, reporting bugs, and suggesting improvements also help.

Sponsorship enquiries are welcome on the donation page as well.

Troubleshooting

Most unusual behaviour comes from one of two browser settings. The questions in each group have a single shared answer.

Canvas pixel access is blocked

If several of these apply, canvas blocking is the likely cause:

  • Why do the extracted colours look random?
  • Why is the image replaced by stripes or noise?
  • Why does clicking the image do nothing?
  • Why does the magnifier show the wrong colours?
  • Why is the exported PNG blank or corrupted?

Privacy-focused browsers and canvas-blocking extensions may block or fake canvas pixel reads. hue.tf needs pixel access for automatic extraction, pin sampling, the magnifier, and PNG rendering. The browser cannot distinguish a local palette tool from a fingerprinting script, so the protection applies to both.

If canvas access is allowed for this site - for example, by whitelisting it in the extension or changing the browser's canvas permission for the site - automatic extraction can work again. This lowers the browser's fingerprinting protection for the site. Refresh the page after changing the setting.

Manual HEX/RGB/HSL editing, shared palettes, SVG exports, code/token exports, and .ASE exports continue to work. The screen eyedropper may also work if the browser supports it.

JavaScript JIT is disabled

If several of these apply, reduced JavaScript performance is the likely cause:

  • Why do changes in the export options lag?
  • Why does the export preview take a long time to update?
  • Why do the laptop fans speed up during export?
  • Why is hue.tf slow in LibreWolf or Mullvad?

Some privacy-hardened browsers disable JavaScript just-in-time (JIT) compilation by default. hue.tf runs palette extraction and canvas rendering in JavaScript, so these operations become CPU-heavy when JIT is unavailable. This can cause lag, slow preview updates, and higher fan activity. It is a performance limitation, not a network transfer.

To reduce the load: use a smaller palette, turn off Include original photo in card, choose Ambient Palette Mesh or Studio Obsidian Solid instead of the blurred image, choose a smaller export ratio, and close other heavy tabs. A browser or profile with JIT enabled will render faster if that trade-off is acceptable.

No image or palette data is sent anywhere in either mode.

How does it work?

hue.tf turns pixels into palettes locally in the browser. No image or palette is sent to a server.

  1. 1

    Decode locally

    The browser decodes the selected image. The file is not uploaded.

  2. 2

    Sample pixels

    A small copy of the image, 220 pixels wide, is sampled with a seeded random generator. Area averaging can smooth noisy images.

  3. 3

    Cluster colours

    Median cut and k-means select representative colours. The seed makes results reproducible, and each colour is linked to a position in the image for the pins.

  4. 4

    Refine and export

    Edit values in HEX, RGB, or HSL; reorder or remove colours; then export as PNG or SVG, CSS/SCSS/Tailwind/JSON, or an .ASE swatch file.

Sharing: share links place the palette in the URL hash. Browsers do not send the hash fragment to servers, but anyone with the link can read the palette. The original image is not included. There are no accounts and no server-side palette storage.
